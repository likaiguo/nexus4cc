# Nexus 产品发布演讲方案（15min · Steve Jobs 风格）

---

## 风格研究摘要

以下规则提炼自 Jobs 历次 Macworld 主题演讲及 Carmine Gallo《The Presentation Secrets of Steve Jobs》：

| 要素 | Jobs 的做法 |
|------|------------|
| **背景** | 深蓝渐变（near-black → dark blue → blue-gray），不是纯黑。有纵深，不刺眼。 |
| **字体** | Myriad（Apple 御用无衬线体）。演讲全程只用这一种字体。 |
| **字号** | 变化范围极大。Hero slide 用 190pt，但信息页可缩到 60pt。统一的是留白量，不是字号。 |
| **文字位置** | 不总是居中。左对齐、右下角、甚至偏在一侧——完全看图片和文字的关系。 |
| **每页字数** | 大量页面 1–2 词或纯图片。iPhone 2007 keynote 到第 10 页才累计满 40 词（普通 PPT 一页就有 40 词）。 |
| **图片** | 图片主导，文字从属——永远不是反过来。全屏照片、产品特写、截图，不配文字或只配 1–2 个词。 |
| **多元素** | Build 逐条出现。永远不一次性全部显示。 |
| **叙事** | 经典三段式 + Hero vs Villain 弧线。开头预告"三件事"。 |
| **标题** | Twitter 式单行标题（≤140 字符），给观众一个可以带走的一句话。 |
| **高潮** | Holy Smokes Moment —— 水冷却器时刻，人们第二天还在谈论的那个瞬间。 |
| **演讲 vs 幻灯片** | 幻灯片**增幅**演讲，绝对不重复演讲。图像 + 说话 = 双通道输入（Cognitive Load Theory）。 |
| **排练** | 连续四小时一轮。看起来举重若轻，因为他练了无数次。 |

## 视觉规范

| 项 | 规则 |
|----|------|
| **背景** | 深蓝渐变：`#0A131E` → `#14263C` → `#516985`（径向或线性渐变，由设计师按实际比例调试）。不是纯黑。 |
| **主文字** | `#FFFFFF`，仅 Myriad Pro（或 SF Pro Display 替代）。全场只用这一种字体。 |
| **点缀色** | Terminal Green `#00E676`。出现位置严格受限——详见下文。 |
| **点缀色出场次数** | 全场仅 **3–4 页**：Hero 页（Slide 6，N 字一竖）、安全感 ✓（Slide 12）、One More Thing（Slide 16，三个词）、结束页（Slide 17，GitHub 地址）。其余一律白。 |
| **字号范围** | Hero 页 150–190pt。单行命题 80–120pt。辅文 48–60pt。最小不低过 30pt（Kawasaki 公式：最年长观众年龄 ÷ 2）。 |
| **对齐** | 文字不总是居中。视画面内容决定——左对齐用于引述/痛点；居中用于 Hero 揭晓；右下角用于署名/来源。 |
| **图片** | 全屏出血。产品截图用设备框套住。照片高质、暗调。需要去饱和的场合降到 80–90%，保留一点色彩信息。 |
| **动画** | 仅两种：Dissolve（淡入淡出）+ Build In（元素依次出现）。无弹跳。无旋转。 |
| **Build 规则** | 同一页有多元素时必须 build —— 一次只出现一个。演讲者说到哪个，哪个才出现。 |
| **禁止** | 列表符号、表格边框、阴影、渐变文字、页码、footer、logo 水印。幻灯片上不出现公司 logo——舞台背景有就够了。 |

## 叙事结构

```
Hero vs Villain 弧线：

Villain  = 传统终端工具：锁在笔记本上、移动端体验灾难、断线丢进度
Hero     = Nexus：随身、发射后不管、为手指设计、永不丢失

三部曲 (Rule of Three)：

  1. 自由 —— AI 不锁在设备上（关掉 ≠ 断开）
  2. 触控 —— 为手指重新设计终端交互
  3. 可靠 —— 什么都不会丢，多项目有序
```

---

## 结构总览（18 页 · ~15min）

```
Act I   预告 + 痛点     3 页  ~2.5min   预告三件事 → Villain 登场
Act II  揭晓 + 原理     4 页  ~3.5min   认识 Hero → 为什么不同
Act III 体验：三个突破  3 页  ~3min     触控、PWA、安全感（分别 build）
Act IV  秩序 + Demo     3 页  ~3min     多项目 → Holy Smokes Moment
Act V   召唤            3 页  ~3min     谁需要 → One More Thing → 开始

幕间插入 2 张纯图过渡页（Slide 5 和 Slide 12），给演讲者换气和观众消化时间。
        ────────────────────────
        共 18 页（含 2 张纯图过渡），约 15–17min
```

>
> 这是「远程工作」在手机上的样子。

> （走近屏幕，指向那个虚拟键盘）
>

### Slide 3 · 洞察（Insight）

> 为什么 AI 被锁在笔记本里？

>
> 但它被锁在一块 14 英寸的屏幕后面。你离开那张桌子，智能就不在了。
>
> 这不合逻辑。
>
> AI 应该跟着你走。在任何设备上。在任何地方。

### Slide 15 · Holy Smokes Moment（Demo）

**画面**：深蓝渐变背景。正中一小行字，约 36pt，Light weight。下方大面积留给外接设备画面（现场投屏）或视频播放区。

**Slide 文字**：

> 眼见为实。

**演讲词**：

> 我不多说了。
>
> 让画面说话。
>
> （舞台灯光暗。播放 Demo 视频 / 现场投屏演示。）

**▸ Demo 视频制作说明（给视频制作者）：**

- **时长**：90 秒严格不超过。（Jobs 的视频从不拖沓。）
- **叙事线**：
  1. iPhone 锁屏 → 解锁 → Safari 打开 Nexus
  2. Project 列表出现，点进 "nexus"
  3. 三个 Channel：#general（绿点 运行中）/ #api（灰点 空闲）/ #deploy（黄点 等待）
  4. 进 #general，Claude Code 正在写代码
  5. 手指在工具栏点 `/` 键，打字：「加一个健康检查端点」
  6. 左滑切到 #api，看看另一个项目
  7. 右滑回到 #general，Claude 已写完——代码和测试都有了
  8. 手指上滑，在文件浏览器里预览生成的文件
  9. 按 Home 键，回到主屏幕
  10. 等待 1 秒。重新点开 Nexus 图标。
  11. 终端还在。输出还在。什么都没丢。
- **视觉**：不需要加任何 UI 标注或箭头。让画面本身说话。黑底绿字终端风格。Nexus 界面直接录屏。
- **配乐**：极简电子。节奏先慢后快，在 "AI 写完代码" 那一刻有个小的情绪上扬。无歌词。
- **结尾帧**：Nexus logo 静置 3 秒。黑屏。

>
> （停顿 2 秒）
>
> 现在，它是你的了。
>
> 去创造一些了不起的东西吧。
>
> （退后一步）

## 演讲排练要点

- **排练量**：至少完整走 5 遍。Jobs 生前通常连续排练数天，每天四小时一轮。
- **过渡页的沉默**：Slide 5 的光标闪烁页和 Slide 12 的咖啡厅照片页，不要说话。站在一旁，让画面工作。这是控制节奏的核心——演讲者越敢沉默，观众越投入。
- **Demo 衔接**：Slide 15 "眼见为实" 说完后立即进入视频。如果现场投屏，确认外接设备在 Slide 14 演讲期间已就绪。Jobs 的习惯是 Demo 前自己亲手插线，不当甩手掌柜。
- **One More Thing 的表演**：Slide 17 时，往舞台边缘走两步，作势要退场，然后转身。"还有一件事。"——不是喊出来，是几乎像突然想起来一样的口吻。
- **穿着**：深色上衣（黑高领或黑 T 恤），深色裤子。舞台背景用深蓝渐变灯光或投影。演讲者在画面中的剪影要与幻灯片色调一致。
- **每页最长停留 ≈ 自己默读三遍的时间**。超过这个时长，要么拆页，要么删内容。
